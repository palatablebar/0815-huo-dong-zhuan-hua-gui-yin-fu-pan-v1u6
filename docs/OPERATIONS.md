# 批次操作

1. 用带异常样例做阶段预览，查看列数、必填值和冲突记录。
2. 执行批次后，在业务阶段定位异常分组并核对原始记录键。
3. 修复来源文件，重新上传并执行。历史批次保留供复核。
4. 对账无差异且无坏行时可签发。对仍有差异的版本可填写暂缓意见。
5. 导出复核证据并保存于交接记录。

单文件 256 KiB，最多 2000 条逻辑记录。容器重启后保留批次。恢复时使用原 Docker Compose 数据卷。

## 实验放量判定

1. 打开 <http://localhost:18309/experiments>，选择「已成熟样例」或「风险样例」。
2. 顶栏查看活动组、继续、观察、回滚计数；未成熟或对照不完整的组显示「观察」，不得放量。
3. 点击活动组查看证据：门槛、成熟度、同周期对照、净增量与阻断记录键。
4. 数据更新或退款晚到时，在「并入批次」填入现有批次号再上传，只重算受影响组。
5. 整批可发布且无回滚时填写发布说明并「发布判定单」。
6. 需要撤回时点「回滚到上一版」，原子切回且旧版证据保留。
7. 下载判定证据归档，内含全部历史版本与审计事件。
